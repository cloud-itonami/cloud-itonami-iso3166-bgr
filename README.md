# cloud-itonami-iso3166-bgr

Open ISO 3166 Blueprint for **BGR**: Republic of Bulgaria.

Independent public-sector market-entry & procurement-compliance service
for an already-incorporated operator entering public contracts in Bulgaria.

## Official surface

- Procurement: CAIS EOP (centralized automated information system for electronic public procurement)
- Business/tax: UIC/BULSTAT commercial registration + VAT via NRA
